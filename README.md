# AirChat 1.0 — экспериментальная офлайн-PWA

Первая тестовая версия на HTML/CSS/JavaScript. Без платных API, без Python, без облачного сервера сообщений. Интерфейс в бежевой палитре.

## Что работает
- PWA-кэширование после первого открытия по HTTPS (например, GitHub Pages).
- Ручной обмен сжатыми WebRTC SDP-кодами: QR (если помещается) или копирование текста.
- Локальный WebRTC DataChannel с обязательным шифрованием транспорта DTLS.
- Код сверки на основе отпечатков сертификатов WebRTC (сверяйте **голосом или лично**).
- Переписка, сохранение в IndexedDB, архив, экспорт JSON, локальное удаление.
- Настройки автоархива и базовый список ранее известных контактов.
- QR-сканирование с камеры/фото **только если браузер поддерживает BarcodeDetector**; на Safari iOS часто не работает. Текстовый код — универсальный запасной вариант.

## Ограничения (важно)
- Для передачи данных нужен **общий локальный Wi-Fi**; QR не является каналом связи. Без интернета WebRTC иногда не может установить соединение даже в одной сети (особенно при изоляции клиентов, особенностях iOS или hotspot).
- После полного закрытия браузера необходимо **заново обменяться кодами**; восстановление списка чатов не восстанавливает WebRTC-сессию.
- В этой версии **нет передачи файлов, групповых чатов, Bluetooth и автоматического поиска**. Это будущие функции.
- Белый список — **экспериментальная** проверка сохранённого идентификатора после подключения, а не полноценная криптографическая аутентификация. Не считайте её достаточной защитой. Всегда сверяйте код безопасности.
- Сохранённые сообщения пока **не зашифрованы в IndexedDB**; шифруется транспорт WebRTC. Экспорт JSON тоже не зашифрован.
- История локальна для конкретного браузера/устройства. При очистке данных сайта она исчезнет. Экспортируйте важные чаты.
- Браузер может блокировать камеру, отключать WebRTC в фоне или при блокировке экрана.
- В некоторых браузерах/сетях QR слишком длинный — используйте текстовый код.
- Приложение предназначено для тестирования, не для конфиденциальных данных.

## Как запустить
1. Загрузите **содержимое** этой папки в публичный репозиторий GitHub.
2. В настройках репозитория Pages → Deploy from a branch → main → / (root).
3. Откройте выданный HTTPS-адрес на обоих телефонах при наличии интернета, дождитесь загрузки; на iPhone через Safari → Поделиться → На экран «Домой».
4. Для теста без интернета подключите оба телефона к одной локальной Wi-Fi сети (можно к точке доступа одного из телефонов). Отключите мобильный интернет, но **оставьте Wi-Fi включённым**.
5. На первом телефоне нажмите «Создать подключение». Передайте QR/текст второму.
6. На втором нажмите «Подключиться», вставьте или отсканируйте код и нажмите «Создать ответ». Передайте полученный ответ первому.
7. На первом вставьте ответ и нажмите «Принять ответ». Сверьте 6-значный код на обоих экранах. Если совпадает и появился статус «Подключено», отправляйте сообщения.
8. Для тестирования камеры на iOS используйте текстовый код, если распознавание QR недоступно.

## Почему QR может не сработать
SDP WebRTC содержит сетевые кандидаты и сертификаты. Даже после сжатия код может быть большим, и камера не всегда распознаёт плотный QR. Поэтому **копирование текстового кода — основной надёжный резервный вариант**. Первая версия — proof of concept, а не обещание бесшовного подключения на всех устройствах.
